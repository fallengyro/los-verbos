# Ruido de fondo — sound credits

Every recording here is from [Freesound](https://freesound.org) under
**Creative Commons 0** (public domain dedication): free to use, change and
share, no attribution required. They're credited anyway, with thanks.

Each file is about a minute of the recording, mono, leveled to −20 LUFS and
made into a seamless loop (the last 3 s crossfaded into the start), encoded
as 64 kbps MP3. The app loops between the `loop` points given for each scene
in escenas.js.
